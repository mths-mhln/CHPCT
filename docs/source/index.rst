CHPCT documentation
===================

This tool determines the single-stage vapour-compression cycle with the highest COP for a given heat source, heat sink, refrigerant and set of component efficiencies. In this cycle the expansion valve is replaced by a turbine expander, which delivers its work to the compressor shaft. The cycle follows from a differential evolution optimization of the compressor pressure ratio, the compressor inlet state and the condenser outlet temperature, subject to the minimum pinch-point temperature differences in the evaporator and condenser.

The pages below only cover the essentials, i.e. how to install the tool, how to run it and which inputs it expects. For the thermodynamic background and the results the reader is referred to the thesis.
